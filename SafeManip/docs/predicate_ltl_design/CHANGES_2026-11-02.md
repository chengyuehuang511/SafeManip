# Metric overlap depth qualification candidate

The separating-axis helper previously minimized unnormalized projection slack
over both face normals and edge cross-products. Cross-product axes do not have
unit length. Parallel axes contribute only the numerical separation epsilon,
so two identical axis-aligned 20 cm boxes returned about 4e-10 m of overlap
instead of 0.2 m. Other orientations could also underestimate depth.

The helper now divides cross-axis slack by the axis length and excludes
degenerate axes from the depth minimum. Its existing separation checks remain
unchanged. This fixes the units of the returned depth without changing collision
geometry, object parameters, native policy thresholds, or LTL formulas.

The affected depth consumer is path-obstruction checking. Intersections alone
are not evidence that the previous metric threshold decisions were correct.
The frozen F26 evaluation must be retained as version-specific evidence, not
presented as a final corrected-monitor evaluation after this discovery.

Six focused DreamTrace regression tests cover identical/partial overlap,
rigid-rotation invariance, separated/touching boxes, 300 independently checked
random box pairs, unchanged intersection decisions, and an AST/formula scope
guard. Four fail on the previous implementation; all six pass on this candidate.
The tests live in DreamTrace's existing tools/native_obb_overlap_units_test.py.

This candidate is not yet approved for fresh gated evaluation. Physical native
capture, online-versus-replay qualification, affected-case review and baseline
remonitoring remain required. No running or completed F26 source was edited.
